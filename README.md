# Minha Universidade

Projeto acadêmico desenvolvido para praticar conceitos básicos de Programação Orientada a Objetos (POO) utilizando Java.

## Tecnologias

- Java
- IntelliJ IDEA

## Conceitos praticados

- Classes e objetos
- Encapsulamento
- Herança
- Abstração
- Polimorfismo
- ArrayList

## Estrutura do projeto

O código-fonte da aplicação está localizado na pasta `src`.

## Como executar

O projeto pode ser executado a partir da classe `Principal`.
